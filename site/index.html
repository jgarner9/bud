hey bud.

A fast, reproducible IDE: Neovim plus one small Go binary that installs, launches, updates and syncs it. Claude Code is built in.

curl -fsSL https://raw.githubusercontent.com/jgarner9/bud/main/install.sh | sh

macOS and Linux, amd64 and arm64. The script checks the release's signature and checksum, then offers to run bud install. Every step, explained.

The whole config ships in the binary

Every machine gets exactly the same editor: plugins pinned in a committed lockfile, synced from the binary, offline. It runs as its own Neovim and never touches ~/.config/nvim. bud uninstall removes it without a trace.

50 ms to the first screen

Neovim 0.12, lazy-loaded, with fzf-lua, blink.cmp, gitsigns, diffview, nvim-dap and rendered markdown. bud doctor times every start and warns past the budget.

Eight languages, one file each

Go, Python, TypeScript, C, Bash, HTML, CSS and Lua come with parsers, a language server, a linter and format on save. Add your own with one Lua file.

Claude Code, built in

One session per project, shared by its pane, inline actions and commit messages. Every edit Claude proposes opens as a diff to accept or reject. How it fits together.

From a note to a fix

Press a key, say what's wrong, and Claude drafts Linear issues you approve before anything is filed. Then hand one back and get a branch to review. The whole flow.

Updates that check themselves

Signed releases install in the background. After each one bud runs its own health checks and rolls back if something that worked now doesn't.
