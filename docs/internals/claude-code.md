# Claude Code and the dashboard banner

How bud finds, checks and sets up Claude Code.

**Claude Code.** `internal/claude` finds the `claude` binary (PATH, else the native installer's `~/.local/bin/claude`) and reads `--version` and `auth status --json` (`Check`; a cloud provider's `apiProvider` becomes `Method`, e.g. "Amazon Bedrock"). When logged out in bud's own dir while `~/.claude/settings.json`'s `env` turns on Bedrock/Vertex/Foundry, `Status.Elsewhere` names it (Lua: `claude.home_provider()`), and status, setup, install, doctor and the session say to share the dir (`ai.claude.config home`) instead of running `claude auth login` (JGA-145); setup and install offer to switch to sharing (`shareClaudeDir`, only when `CLAUDE_CONFIG_DIR` is bud's own, D76). `bud claude status|setup` (`internal/cli/claude.go`): `setup` runs Anthropic's native installer (`claude.InstallScript`, after showing it and asking, or with `--yes`), then hands over to `claude auth login`, which needs a terminal. `bud install` offers it when `ai.claude.autostart` is on (`installClaude`) and only warns if it fails. bud sets up no Claude Code configuration: it has no kit (`bud kit sync` was removed in 2.0, D144; the plugin bud ships, `bud-ide`, is handed to its own sessions with `--plugin-dir`, see cli.md) and no configuration repo (clod, removed in 2.0, D143): MCP servers, settings and rules in `~/.claude` are the user's own, and bud only reads them. A `clod` key left in `config.json`, or a `clod.json`/`clod-declined` file in the state dir from an older bud, is ignored: config keeps unknown keys on save (`TestOldClodKeyStillLoadsAndSaves`), and no migration removes the dead key, since a Lua migration rewriting JSON would lose its formatting for no gain. Claude Code config dir (D73, D77, JGA-169): bud shares `~/.claude` by default (`ai.claude.config` `home`); with `bud`, `cli.UseClaudeConfig` (from `main`, never in tests) sets `CLAUDE_CONFIG_DIR` to `paths.ClaudeConfig()` unless it's already set. Doctor's `claude code` check (`doctor.ClaudeCheck`) only ever warns, with fix `bud claude setup`; the dashboard pulls it out of the doctor count into its own banner, and `c` runs the fix. bud stores no keys (D26). Tests swap `checkClaude` and `runOnTerminal`.
